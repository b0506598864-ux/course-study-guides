# איך קבצי אפליקציית React מתחברים

מזהה לימוד ARCH-01. קודם מבינים איפה כל דבר נמצא ומי משתמש בו, ורק אחר כך מפרקים תחביר ורינדור. המבנה כאן מבוסס על lab_1 של המרצה בשיעור 7 באוקטובר, קומיט 04d81ce. דוגמת FilterPanel בהמשך היא תרגול מוצע, לא רכיב שהמרצה כבר יצר.

## ARCH-01A מילון קצר

| מילה | איך קוראים | מה זה |
| --- | --- | --- |
| Architecture | ארכיטקטורה | חלוקת התפקידים והחיבורים באפליקציה |
| Page | פייג׳ | רכיב שמייצג עמוד שלם |
| Component | קומפוננטה | חלק ממשק: למשל טבלה או מסנן |
| Route | ראוט | התאמה בין כתובת לרכיב שיוצג |
| Import | אימפורט | שימוש בקוד שיוצא מקובץ אחר |
| Props | פרופס | ערכים ופונקציות שרכיב מקבל מההורה שלו |
| Store | סטור | מקום מרכזי לנתונים המנוהלים ב־Redux |
| Render | רנדר | חישוב התצוגה ב־React; אינו אומר שכל ה־HTML נבנה מחדש |

Page הוא גם Component. ההפרדה לתיקיות היא ארגון שהמתכנת בוחר, לא מנגנון שמפעיל קובץ אוטומטית.

## ARCH-01B מה קיים בתחילת הפרויקט

בתבנית Vite כבר קיימים package.json, index.html, src/main.tsx ו־src/App.tsx, וקובצי הגדרות TypeScript ו־Vite. לא מתחילים בהמצאת כל אלה מחדש. package.json מכיל את scripts ואת החבילות. npm run dev מפעיל כאן את vite.

| קובץ | האחריות שלו | החיבור הבא |
| --- | --- | --- |
| index.html | דף HTML ובו מקום לאפליקציה, root | טוען את main.tsx |
| main.tsx | מחבר React ל־root ומגדיר עיצוב כללי | מציג App |
| App.tsx | מחבר Provider של Redux, Router ונתיבים | בוחר עמוד לפי הכתובת |
| navigation.ts | רשימת קישורי התפריט | AppShell קורא את הרשימה |
| components/AppShell/index.tsx | מסגרת משותפת ותפריט | Outlet מציג את העמוד המתאים |
| pages/DogsPage/index.tsx | עמוד הכלבים | משתמש ברכיבים ובנתונים |
| store/store.ts | מחבר reducers למאגר אחד | Provider מאפשר לרכיבים לגשת אליו |

בפרויקט הזה Provider נמצא ב־App.tsx, לא ב־main.tsx. בפרויקטים אחרים המיקום עשוי להיות שונה.

## ARCH-01C מי מפעיל את מי

1. הדפדפן טוען index.html.
2. main.tsx מפעיל createRoot(...).render ומציג App.
3. App מגדיר איזה רכיב שייך לכל כתובת.
4. AppShell מציג את התפריט ואת Outlet.
5. בכתובת /dogs, DogsLayout מוצג; ה־Outlet הפנימי שלו מציג DogsPage או DogsReportsPage לפי הנתיב.
6. DogsPage מחזיר JSX שמכיל את החלקים של העמוד.

אין צורך לרשום כל Component ב־App. רושמים שם Route כאשר מוסיפים עמוד עם כתובת. רכיב פנימי מחברים במקום שבו רוצים להציג אותו.

## ARCH-01D מוסיפים עמוד חדש

דוגמה מהמרצה: LoginPageRef.

1. יוצרים קובץ pages/LoginPageRef/index.tsx שמייצא רכיב.
2. ב־App.tsx מייבאים אותו:
   `import LoginPageRef from './pages/LoginPageRef'`
3. מוסיפים בתוך Routes את הנתיב:
   `<Route path="login-ref" element={<LoginPageRef />} />`
4. אם רוצים קישור בתפריט, מוסיפים ל־navItems ב־navigation.ts פריט עם to, label ו־icon.

יצירת תיקייה בלבד לא מוסיפה נתיב. הוספת קישור בלבד לא מגדירה עמוד. אפשר להגיע לנתיב גם בלי קישור בתפריט, אם ה־Route מוגדר.

לא מוסיפים עמוד ל־Store. ה־Store אינו רשימת עמודים.

## ARCH-01E מוסיפים רכיב מסנן

דוגמה לימודית: FilterPanel בתוך עמוד הכלבים.

| פעולה | איפה כותבים |
| --- | --- |
| מציגים תיבת חיפוש ואפשרויות | components/FilterPanel/index.tsx |
| מייבאים ומציגים את המסנן | pages/DogsPage/index.tsx |
| מחזיקים טקסט חיפוש מקומי | useState בעמוד, אם הוא בעל הנתון |
| מעבירים טקסט למסנן | prop בשם query שנבחר לצורך הדוגמה |
| מודיעים להורה שהטקסט השתנה | callback prop בשם onQueryChange |
| מחשבים אילו כלבים להציג | פונקציית סינון, בדומה ל־dog-filters.ts |
| מציגים את התוצאה | הטבלה בעמוד |

למשל, העמוד יוכל להציג:
`<FilterPanel query={query} onQueryChange={setQuery} />`

השמות FilterPanel, query ו־onQueryChange בדוגמה נבחרו בידי המתכנת. יצירת תיקיית components אינה מפעילה את הרכיב; import והשימוש ב־JSX הם החיבור.

לא מוסיפים Route למסנן פנימי. לא חייבים Redux רק מפני שהוספנו Component.

## ARCH-01F מתי כן משנים Store

אם כמה עמודים צריכים אותה רשימה, אפשר לשמור אותה ב־Redux. בפרויקט המרצה רשימת הכלבים משותפת לטבלה ולדוחות.

1. קובץ reducer מגדיר את המצב ההתחלתי ואת התגובות לפעולות.
2. store.ts מחבר reducer חדש תחת מפתח, לדוגמה dogs.
3. useAppSelector קורא נתונים מהנתיב state.dogs.
4. useAppDispatch מספק dispatch, שבאמצעותו שולחים פעולות.

אם רק הוספנו שדה ל־settingsReducer שכבר מחובר, בדרך כלל אין צורך לרשום אותו מחדש ב־store.ts.

ה־Provider מספק גישה ל־Store; הוא לא טוען בעצמו נתונים מהשרת. Router בוחר עמוד; הוא לא מנהל את רשימת הכלבים.

## ARCH-01H בדיקת הבנה לפני קוד
