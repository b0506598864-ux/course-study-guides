# מסמכים לשיתוף עם הכיתה

- `מדריך-מעבר-למורה-החדש.docx` — מסמך קבוצתי שמסביר מה הכיתה כבר יודעת, אילו נושאים עדיין חדשים, מה ההבדל בין שיטת שחר לשיטת גל, כיצד גל מגיב לשאלות, מילון אנגלית קצר ושיטת עבודה מומלצת.
- [`המעבר-משחר-לגל-תמונת-מצב-ופתרון.pdf`](../../output/pdf/המעבר-משחר-לגל-תמונת-מצב-ופתרון.pdf) — גרסת PDF מימין לשמאל, בשני חלקים: הסבר לתלמידים ותמונת מצב עניינית למרצה או לרכזת.
- [`המעבר-משחר-לגל-מימין-לשמאל.docx`](../../output/docx/המעבר-משחר-לגל-מימין-לשמאל.docx) — גרסת Word פתוחה לעריכה, עם כיוון עברי גם בפסקאות וגם בטבלאות.

המסמך מבוסס על התמלולים וקוד השיעור. הוא אינו ביקורת אישית ואינו כולל שמות של תלמידים.
