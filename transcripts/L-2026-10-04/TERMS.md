# המונחים שתוקנו בתמלול

הטבלה מציגה כתיב ולא הגדרה: מונח באנגלית אינו בהכרח פקודה או שם משתנה. שמות מתכנת ומילים כלליות לא הומרו למזהי קוד על סמך דמיון בלבד.

| בתמלול המקורי | הכתיב באנגלית |
|---|---|
| ג'אווה סקריפט | `JavaScript` |
| יוז קונטקסט | `useContext` |
| טי אס איקס | `TSX` |
| קומפוננטות | `components` |
| אי פי איי | `API` |
| קומפוננטה | `component` |
| יוז אפקט | `useEffect` |
| אי פי אי | `API` |
| פרוביידר | `Provider` |
| קומפוננט | `component` |
| אינפוטים | `inputs` |
| סטייטים | `states` |
| קונטקסט | `context` |
| רדיוסר | `reducer` |
| סטייטס | `states` |
| דיספאץ | `dispatch` |
| אינפוט | `input` |
| רידקס | `Redux` |
| ריאקט | `React` |
| סטייט | `state` |
| ראוטר | `router` |
| הוקים | `hooks` |
| ראוט | `Route` |
| סטור | `store` |
