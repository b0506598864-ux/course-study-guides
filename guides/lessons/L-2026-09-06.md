## L-2026-09-06-S02 — Function Overload

Overload מגדיר כמה צורות חוקיות לאותה פונקציה, למשל מספר עם מספר או מחרוזת עם מחרוזת. חתימות הטיפוסים מנחות את TypeScript ונעלמות מה-JavaScript שנוצר.

```ts
function add(a: number, b: number): number;
function add(a: string, b: string): string;
function add(a: number | string, b: number | string): number | string {
  if (typeof a === "number" && typeof b === "number") return a + b;
  return String(a) + String(b);
}
```

## L-2026-09-06-S03 — interface ו-enum

`interface` הוא חוזה המתאר אילו שדות חייבים להיות באובייקט. `?` מסמן שדה רשות. `extends` מאפשר ל-interface חדש לקבל שדות מבסיס ולהוסיף משלו.

```ts
interface User {
  id: number;
  name: string;
  age?: number;
}
```

אפשר להכריז פעמיים על interface באותו שם וההכרזות יתמזגו. גל הזהיר שזה עלול לבלבל כשהן נמצאות בקבצים שונים. Type Alias, לעומת זאת, אינו ניתן להכרזה חוזרת באותו שם.

`enum` הוא אוסף סגור של ערכים קבועים, למשל מצב הזמנה או תפקיד. בניגוד ל-Type Alias שנועד לבדיקת טיפוסים, `enum` קיים גם בזמן הריצה.

```ts
enum OrderStatus {
  Pending = "pending",
  Shipped = "shipped"
}
```

## L-2026-09-06-S04 — any מול Generic

`any` אומר ל-TypeScript כמעט לא לבדוק את הערך. גל אמר להשתמש בו רק כשיש סיבה טובה מאוד; בפרויקטים רבים אוסרים עליו.

Generic שומר את הקשר בין הקלט לפלט:

```ts
function getLastItem<T>(array: T[]): T {
  return array[array.length - 1];
}
```

- `<T>` מכריז על פרמטר של טיפוס.
- `T[]` הוא מערך מאותו טיפוס.
- `: T` הוא טיפוס הערך שחוזר.
- `T` הוא שם שהמתכנת בוחר; אפשר לבחור שם אחר ולהשתמש בו בעקביות.
- Generic אינו תחליף ל-`interface extends`; הוא כלי לשימוש חוזר בלי לאבד טיפוסים.

## L-2026-09-06-S05 — שני טיפוסים, Tuple, Spread ו-Merge

```ts
function swap<T, U>(pair: [T, U]): [U, T] {
  const [left, right] = pair;
  return [right, left];
}
```

`[T, U]` הוא Tuple: מערך שבו מספר המקומות והטיפוס בכל מקום ידועים. `<T, U>` מתאים כששני הצדדים עשויים להיות מטיפוסים שונים.

```ts
const merged = { ...user, ...user2 };
```

`...` הוא Spread Operator. הוא פותח את שדות שני האובייקטים לתוך אובייקט חדש ובאותה רמה. `{ user, user2 }` היה יוצר שני אובייקטים מקוננים.

## L-2026-09-06-S06 — keyof, ‏K extends keyof T ו-T[K]

```ts
function getField<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

- `keyof T` — שמות השדות החוקיים של `T`.
- `K extends keyof T` — `K` חייב להיות שם שדה אמיתי.
- `T[K]` — טיפוס התוצאה הוא הטיפוס המדויק של השדה שנבחר.

כך שגיאת כתיב בשם שדה נחסמת בזמן הכתיבה במקום להחזיר `undefined` בהרצה. גל ציין שימושים בחיפוש, עדכון שדות ועמודות טבלה.

## L-2026-09-06-S07 — Pick, ‏Omit ו-Record

```ts
type PublicUser = Pick<User, "id" | "name">;
type UserWithoutPassword = Omit<User, "password">;
type Labels = Record<keyof Product, string>;
```

- `Pick` משאיר רק שדות שנבחרו.
- `Omit` משמיט שדות שנבחרו.
- `Record` דורש ערך מטיפוס מסוים עבור כל מפתח מותר.

## L-2026-09-06-S08 — מבוא ל-React

- **React** — ספרייה לבניית ממשק משתמש, לא Framework מלא. Routing ו-State Management עשויים לדרוש חבילות נוספות.
- **SPA** — הדף הראשי נטען פעם אחת ובהמשך מחליפים רק את התוכן הדרוש.
- **Component** — חלק עצמאי ושימושי-מחדש של הממשק, למשל Header.
- **TSX** — תחביר שנראה כמו HTML בתוך TypeScript, אך דורש קומפילציה.
- **Props** — מידע שמעבירים לקומפוננטה כדי להתאים אותה.
- **Parent/Fragment** — קומפוננטה מחזירה הורה אחד שעוטף את התוכן.
- **Virtual DOM** — React משווה תצוגה קודמת לחדשה ומעדכנת רק מה שהשתנה.

בקורס React ייכתב עם TypeScript, לא עם JavaScript בלבד. לא משנים את ה-DOM ידנית; React אחראית עליו.
