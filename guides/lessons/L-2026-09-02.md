## L-2026-09-02-S01 - הרעיון המרכזי

TypeScript היא JavaScript עם בדיקת טיפוסים בזמן הכתיבה והקומפילציה. הדפדפן אינו מריץ את קובץ ה-`.ts` ישירות; הפקודה `tsc` מתרגמת אותו לקובץ JavaScript בתיקיית `dist`, ואת קובץ ה-`.js` מחברים ל-HTML.

```text
src/index.ts -> tsc -> dist/index.js -> index.html
```

## מה נלמד בשפה פשוטה

1. התקנת Node.js, שמגיעה יחד עם `npm`.
2. יצירת פרויקט בעזרת `npm init` וקובץ `package.json`.
3. התקנת TypeScript ויצירת `tsconfig.json`.
4. הוספת טיפוסים בסיסיים: `string`, ‏`number`, ‏`boolean`.
5. הוספת טיפוס לפרמטר של פונקציה ולטיפוס שהיא מחזירה.
6. הפרדה בין קוד מקור בתיקיית `src` לבין JavaScript שנוצר בתיקיית `dist`.
7. הרצת קומפילציה רציפה עם `tsc --watch`.
8. חיבור קובץ JavaScript שנוצר אל HTML.
9. תרגול DOM עם `getElementById`, ‏`innerHTML` ו-`setTimeout`.
10. התקנת Axios, אך בקוד השיעור עדיין אין שימוש ממשי בו.

## L-2026-09-02-S02 - הטיפוסים הבסיסיים

| TypeScript | בעברית | דוגמה |
|---|---|---|
| `string` | מחרוזת / טקסט | `"Notebook"` |
| `number` | מספר שלם או עשרוני | `19.9`, ‏`3` |
| `boolean` | אמת או שקר | `true`, ‏`false` |

הכתיבה הכללית היא:

```ts
const variableName: type = value;
```

- `const` היא מילת JavaScript קבועה.
- `variableName` הוא שם שהמתכנת בוחר.
- הנקודתיים `:` אומרות: עכשיו מציינים את הטיפוס.
- `type` מוחלף ב-`string`, ‏`number` או `boolean`.
- `value` הוא הערך שהמתכנת מכניס.

## L-2026-09-02-S03 - טיפוסים בפונקציה

```ts
function calcSubtotal(unitPrice: number, quantity: number): number {
    return unitPrice * quantity;
}
```

- `function`, הסוגריים והסוגריים המסולסלים הם מבנה קבוע של JavaScript/TypeScript.
- `calcSubtotal`, ‏`unitPrice` ו-`quantity` הם שמות שהמתכנת בחר.
- `: number` אחרי כל פרמטר קובע איזה ערך מותר להכניס.
- `: number` שאחרי הסוגריים קובע שהפונקציה חייבת להחזיר מספר.
- `return` מחזיר את התוצאה למקום שקרא לפונקציה.

## L-2026-09-02-S04 - קובצי הפרויקט

- `src/` - קוד TypeScript שהמתכנת כותב.
- `dist/` - קוד JavaScript שנוצר אוטומטית מהקומפילציה.
- `package.json` - שם הפרויקט, החבילות והפקודות שאפשר להריץ.
- `package-lock.json` - נוצר אוטומטית ושומר גרסאות מדויקות של החבילות.
- `tsconfig.json` - הגדרות הקומפיילר של TypeScript.
- `node_modules/` - החבילות שהותקנו. לא לומדים ולא עורכים את הקבצים שבתוכה.

## L-2026-09-02-S05 - הגדרות tsconfig

```json
{
  "compilerOptions": {
    "rootDir": "./src",
    "outDir": "./dist",
    "strict": true,
    "noEmitOnError": true
  },
  "exclude": ["node_modules", "dist"]
}
```

- `rootDir` - מאיפה לקרוא את קובצי ה-TypeScript.
- `outDir` - לאן לשמור את קובצי ה-JavaScript שנוצרו.
- `strict` - מפעיל בדיקות טיפוסים מחמירות.
- `noEmitOnError` - לא יוצר JavaScript אם קיימת שגיאת TypeScript.
- `exclude` - תיקיות שלא צריך לקמפל.

## L-2026-09-02-S06 - npm והפקודות החדשות

| פקודה | מה היא עושה |
|---|---|
| `node -v` | בודקת איזו גרסת Node.js מותקנת |
| `npm -v` | בודקת איזו גרסת npm מותקנת |
| `npm init` | יוצרת `package.json` |
| `npm install` | מתקינה את החבילות הרשומות בפרויקט |
| `npm i axios` | מתקינה את ספריית Axios |
| `npm i typescript --save-dev` | מתקינה TypeScript כחבילת פיתוח בפרויקט |
| `npm i typescript -g` | מתקינה את פקודת TypeScript בכל המחשב |
| `tsc --init` | יוצרת `tsconfig.json` |
| `tsc` | מקמפלת TypeScript ל-JavaScript פעם אחת |
| `tsc --watch` | ממשיכה לעקוב ומקמפלת אחרי כל שמירה |
| `npm run compile` | מריצה את הסקריפט `compile` מתוך `package.json` |
