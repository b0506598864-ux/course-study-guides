# תמלול שיעור 4 באוקטובר

התמלול עדיין חסר. בבדיקה ב־8 באוקטובר נמצאה בתיקיית השיעור המקומית תיקיית תמלול עם README בלבד. לא נמצא קובץ כתוביות גם בחיפוש בתיקיית ההקלטות וההורדות.

נדרש קובץ VTT, SRT או טקסט של ההקלטה כדי לתקן את המונחים ולשמור את הזמנים. קוד המרצה יכול לעזור לזהות כתיב של פקודות, אבל אינו תחליף לדברים שנאמרו בשיעור. לא נוצר כאן תמלול משוער.
