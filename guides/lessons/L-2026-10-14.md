## תוספות המעבדה האחרונה

UUID הוא מזהה שנוצר לבקשה. בקוד הוא נשלח ב־Header בשם x-request-id, ונכלל בתיעוד שגיאות כדי לעזור לקשר בין תשובת שגיאה לבקשה שלה.

ב־lab_4 הקובץ src/index.ts מחבר Middleware ונתיבים; src/middleware.ts מגדיר את הפונקציות; src/routes/login/index.ts יוצר Router שמחובר תחת /auth. לכן הכתובת של healthcheck היא GET /auth/healthcheck, והכתובת של login היא POST /auth/login. האחרון עדיין מחזיר טקסט דוגמה ואינו אימות משתמשים מלא. app.use(authorize) מופיע כהערה בגרסה שנבדקה.

פקודות שהוגדרו ב־lab_4: npm start מפעיל tsx watch; npm run build מריץ tsc; npm run typecheck בודק טיפוסים ללא יצירת פלט. אלו פקודות שונות מפרויקט React ויש להריץ בתיקיית המעבדה המתאימה.

לא נמצאה בקוד המעבדות משימה מתוזמנת של node-cron, אף שהספרייה מותקנת ומיובאת. בחלק א׳, 00:38:53–00:41:06, כן מוזכרת דוגמה של פעולה חוזרת ושמירת התהליך פעיל; הפקודה המדויקת אינה קריאה מספיק כדי לשחזר אותה מן התמלול.
