# L-2026-09-06 — TypeScript: interface, enum, Generics ו-keyof

## סיכום פשוט

המקור שנבדק הוא מאגר המרצה ב-commit `a34c64e`. עדיין אין תמלול, ולכן ההוראות שלהלן הן הוראות כתובות מה-README ולא ציטוטים מהמרצה.

## L-2026-09-06-S01 — interface

`interface` הוא תיאור של המבנה שאובייקט חייב לקיים.

```ts
interface User {
  id: number;
  name: string;
  email: string;
  isActive: boolean;
  age?: number;
}
```

- `interface` היא מילת TypeScript קבועה.
- `User`, ‏`id`, ‏`name` ושאר השמות נבחרים על ידי המתכנת.
- `?` אומר שהשדה אינו חובה.
- `extends` בין interfaces אומר שממשק חדש מקבל את השדות של ממשק קיים ומוסיף עליהם.

## L-2026-09-06-S02 — enum

`enum` נותן שמות לקבוצה סגורה של ערכים קבועים.

```ts
enum OrderStatus {
  Pending = "pending",
  Shipped = "shipped",
  Delivered = "delivered"
}
```

במקום לזכור טקסטים חופשיים משתמשים למשל ב-`OrderStatus.Pending`.

## L-2026-09-06-S03 — any מול Generic

`any` מבטל כמעט את בדיקת הטיפוסים. Generic שומר את הקשר בין הטיפוס שנכנס לטיפוס שיוצא.

```ts
function getLastItem<T>(array: T[]): T {
  return array[array.length - 1] as T;
}
```

- `<T>` מצהיר על טיפוס זמני שהפונקציה תקבל בזמן השימוש.
- `T[]` הוא מערך מאותו טיפוס.
- `: T` אומר שהפונקציה מחזירה אותו טיפוס.
- האות `T` היא שם שהמתכנת בוחר; אפשר היה לבחור שם אחר.

## L-2026-09-06-S04 — שני טיפוסים כלליים

כאשר שני הצדדים אינם חייבים להיות מאותו טיפוס משתמשים ב-`<T, U>`.

```ts
function swap<T, U>(pair: [T, U]): [U, T] {
  const [left, right] = pair;
  return [right, left];
}
```

`swap(["pen", 10])` מקבלת `[string, number]` ומחזירה `[number, string]`.

## L-2026-09-06-S05 — keyof

`keyof` יוצר טיפוס שמכיל רק את שמות השדות של אובייקט.

```ts
type User = { id: number; name: string };
type UserKey = keyof User;
```

`UserKey` הוא למעשה `"id" | "name"`. לכן TypeScript יכול למנוע כתיבה של שם שדה שאינו קיים.

## L-2026-09-06-S06 — K extends keyof T ו-T[K]

```ts
function getField<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

- `K extends keyof T` — המפתח חייב להיות אחד משמות השדות האמיתיים של `T`.
- `T[K]` — טיפוס התוצאה מתאים לשדה שנבחר.
- אם בוחרים `name`, התוצאה היא `string`; אם בוחרים `price`, התוצאה היא `number`.

## L-2026-09-06-S07 — Record

`Record` בונה טיפוס של אובייקט שבו יש רשימת מפתחות ידועה וטיפוס ערך ידוע.

```ts
type Labels = Record<keyof Product, string>;
```

כאן חייבים לכתוב תווית מסוג `string` לכל שדה של `Product`.

## L-2026-09-06-S08 — Tuple

Tuple הוא מערך שמספר המקומות והטיפוס בכל מקום ידועים מראש.

```ts
const pair: [string, number] = ["pen", 10];
```

המקום הראשון חייב להיות מחרוזת והשני חייב להיות מספר.

## L-2026-09-06-S09 — Intersection

הסימן `&` בין טיפוסים אומר שהתוצאה צריכה לכלול את שני המבנים.

```ts
function merge<T, U>(a: T, b: U): T & U {
  return { ...a, ...b };
}
```

## L-2026-09-06-S10 — Result<T, E>

`Result` מתאר שתי אפשרויות: הצלחה עם ערך או כישלון עם שגיאה.

```ts
type Result<T, E> =
  | { ok: true; value: T }
  | { ok: false; error: E };
```

בדיקה של `if (result.ok)` מאפשרת ל-TypeScript לדעת שבענף הזה קיים `value`; ב-`else` קיים `error`.
