# מסמכים לשיתוף עם הכיתה

- `מדריך-מעבר-למורה-החדש.docx` — מסמך קבוצתי שמסביר מה הכיתה כבר יודעת, אילו נושאים עדיין חדשים, מה ההבדל בין שיטת שחר לשיטת גל, כיצד גל מגיב לשאלות, מילון אנגלית קצר ושיטת עבודה מומלצת.

המסמך מבוסס על התמלולים וקוד השיעור. הוא אינו ביקורת אישית ואינו כולל שמות של תלמידים.
